Reactive Omni Buildathon · in development

An AI agent can ask to pay. Reactive decides if it may.

The agent's funds sit in a vault that only takes payment proposals. A reactive contract on Reactive Network watches every vault event across chains and, when something looks wrong, calls back to freeze the vault or quarantine an attacker. No server, no keeper, no human on call.

  1. Agent proposesGuardVault on Base Sepolia checks the payee, label, cap and daily limit.
  2. Vault emitsEvery proposal, refusal and payee change is an event.
  3. Reactive reactsGuardReactive on Lasna subscribes and applies the rules.
  4. Callback actsFreeze, quarantine, or warn other chains, in one cross-chain callback.
