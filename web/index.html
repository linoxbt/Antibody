The attack

Anyone can send your agent a coin. The coin can talk.

Steward pays Ada's rent from a Sui wallet and remembers across sessions. A stranger sends it a token whose description is an instruction. Memory makes that sentence permanent.

How it works

Four mechanisms. None of them trust the model.

✦
01

Sign every memory

Each write is an Ed25519-signed envelope from one of four lane keys the owner labelled on-chain: user, agent, wallet-objects, control.

⟿
02

Trace every read

Whatever a turn read becomes the parent of whatever it writes. Summarising an untrusted coin yields an untrusted summary.

⬡
03

Decide in code

A pure policy pays only payees Ada signed, within cap, after an exact dry-run on Sui. Citations and confidence count for nothing.

◎
04

Quarantine & learn

Cut a source out of the agent's context without deleting it, rebuild the same state anywhere, and recognise the attacker next time.

It learns

Memory that only remembers is a liability. Memory that learns is the product.

Every confirmed quarantine becomes a lesson written to the ledger on Walrus. The sentinel recalls lessons on every scan, so the second attack never reaches Steward at all.

    Ada confirms a quarantine

    One ledger record excludes the coin, Steward's note and the blocked decision.

  2. 2

  3. 3

  4. 4

Security guarantees

Twelve invariants. Each one attacked by a test.

I-1 · I-2

Lane binding, default deny

A memory's author is the on-chain label of its signing key. Anything unverifiable is never trusted.

I-3 · I-4

Taint is monotonic

Parents are set by the runtime, never the model, and the model's key can't mint trusted facts.

I-5 · I-6

Payments by code, fail closed

No verified ledger, no chain read, no exact dry-run: no payment.

I-7 · I-8

Exclusion, not deletion

Quarantine is recomputed at every projection, so later descendants are excluded too.

I-10 · I-11

Deterministic, tamper-evident

A fresh machine rebuilds the same projection digest from Walrus and Sui alone.

I-9 · I-12

Separated keys and powers

Model, control, signer, ingest and human each run as their own process with one key.

Agent payments

Pays bills over x402. Under the same rules.

When a utility answers HTTP 402, its payTo becomes an ordinary proposal. The signer signs the Sui transaction without executing it and the facilitator settles. A bill server that names any other address is blocked like any unknown recipient.

# Steward: "Pay the electricity bill"
GET /bill/2026-11                     402 Payment Required
  PAYMENT-REQUIRED  exact · sui:mainnet · 42.5 USDC → 0x0c17…0e1e
# policy: payee "utility" registered, within cap, dry-run exact
ALLOW  signer signs (does not execute)
GET /bill/2026-11  PAYMENT-SIGNATURE  200 OK
  PAYMENT-RESPONSE  success · settled on Sui · tx ChyJ…cC5

# same bill, server swaps payTo to 0xbad0…
BLOCK LABEL_MISMATCH  nothing signed
