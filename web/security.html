Trust assumptions, stated

What Antibody relies on, and what happens when it fails.

Owner wallet

The root of trust. If it is compromised, lanes can be re-labelled.

Walrus Memory relayer

Sees plaintext and reports the inventory. A lying relayer turns into blocked payments, never wrong ones.

Tatum gateway

Returns correct Sui state. Chain-read failures fail closed.

Forward-only revocation

A removed key can still decrypt what it saved before. Revocation cuts the writer, not old secrecy.
